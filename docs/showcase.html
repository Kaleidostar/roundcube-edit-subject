Roundcube-Plugin · edit_subject 1.0.3

Den Betreff einer Mail nachträglich ändern

Eine Mail, die schon im Postfach liegt, bekommt einen neuen Betreff. Die Änderung steht in der Mail selbst und ist in jedem Mailprogramm sichtbar, nicht nur in Roundcube.

IMAP-Nachrichten lassen sich auf dem Server nicht verändern. Das Plugin legt deshalb eine geänderte Fassung im selben Ordner ab, prüft sie und löscht erst danach das Original.

  • Roundcube 1.6 und 1.7, Skin Elastic
  • PHP ab 8.1
  • IMAP-Server mit UIDPLUS
  • Deutsch und Englisch
  • GPL-3.0-or-later

Ausprobieren

Eine Mail wählen, über Mehr den Eintrag Betreff bearbeiten öffnen und speichern. Rechts steht, was dabei auf dem IMAP-Server passiert, darunter, was sich im Kopf der Mail ändert. Mit den Schaltern am Server lassen sich Fehlerfälle durchspielen.

Posteingang
Betreff bearbeiten

Die Mail wird auf dem Server durch eine geänderte Fassung ersetzt.

Nur der Betreff ändert sich

Das Plugin ersetzt das Subject-Feld an derselben Stelle; trägt eine Mail mehrere, dann das letzte, denn das zeigt Roundcube an. Alle anderen Kopfzeilen und der Körper bleiben Byte für Byte erhalten, ebenso Flags und Eingangsdatum. Zeichen außerhalb von ASCII schreibt es als UTF-8-Encoded-Words nach RFC 2047.

    Installation
    
    
    Voraussetzungen: Roundcube 1.7 (getestet mit 1.7.6) oder 1.6 (getestet mit 1.6.21) mit dem Skin Elastic, PHP ab 8.1 und ein IMAP-Server mit UIDPLUS. Meldet der Server Zugriffsrechte (ACL), braucht das Konto im Ordner die Rechte i, t und e, bei Mails mit Markierungen zusätzlich s und w.
    
  
    
  
      
    
    1. 
      
      Das ZIP im Verzeichnis plugins/ der Roundcube-Installation entpacken. Es entsteht plugins/edit_subject/.
      
      
      cd /pfad/zu/roundcube/plugins
unzip edit_subject-1.0.3.zip
      
    
      2. 
    
    2. 
      
      Das Plugin in config/config.inc.php aktivieren:
      
      
      $config['plugins'] = ['edit_subject' /* , weitere Plugins */];
      
    
      3. 
    
    3. 
      
      Optional config.inc.php.dist im Plugin-Verzeichnis nach config.inc.php kopieren und edit_subject_keep_original setzen. Ein Datenbankschema ist nicht nötig.
      
    
      4. 
  
    
  
    Im Docker-Image roundcube/roundcubemail das Verzeichnis nach /var/www/html/plugins/edit_subject einhängen und edit_subject in ROUNDCUBEMAIL_PLUGINS aufnehmen.
    

    


    
  
    Gut zu wissen
    
  
      
    
    • Neue UIDFür den Server ist die Mail danach eine neue Nachricht. Andere IMAP-Programme sehen beim nächsten Abgleich eine entfernte und eine neue Mail. POP3-Abrufe, die Mails auf dem Server lassen, laden sie unter Umständen erneut herunter.
      • 
    
    • DKIMSignaturen über das Feld Subject werden ungültig, das betrifft praktisch jede DKIM-Signatur. S/MIME- und PGP/MIME-Signaturen über den Körper bleiben gültig.
      • 
    
    • QuotaWährend des Vorgangs liegt die Mail kurz doppelt im Postfach. Ist es voll, scheitert das Ablegen der Kopie, und das Original bleibt unverändert.
      • 
    
    • ReihenfolgeNach dem Speichern steht die Mail an der alten Stelle. Beim nächsten Neuladen ordnet Roundcube sie nach der gewählten Sortierung ein; mit der Voreinstellung (keine Sortierung, absteigend) steht sie dann oben.
